## 1. 产品定义

把游戏、电影、书籍、餐厅和日常活动装入集合，通过有仪式感的随机抽取选下一件事，并记录是否行动。目标是减少反复比较的阻力，不承诺随机结果最优；允许再抽、暂时不做和编辑。

自用优先、开源免费、无广告和付费限制、本地无账号、少量但精致、轻负担、规则透明。统计不做排行榜、奖惩、连续打卡或道德评价。集合可定义“怎样算做过”，不自动验证。示例：游戏今天玩过即可、电影看完、书籍读 20 分钟、周末实际尝试、餐厅实际选择。

## 3. 术语与信息架构

Collection 为集合；Item 为选项；DrawRecord 为一次成功持久化的抽取；Cycle 保存整轮不重复的已消耗 ID。完成状态属于记录，不属于选项。一个选项可对应多条记录。

内部状态为 pending、completed、skipped；面向用户统一称“待行动”“已做过”“这次不做”。使用“集合”“选项”“执行率”，不暴露数组、事务、schema 等实现词。

底部三个入口：集合、记录、回顾。设置在集合页右上角。集合详情以抽取为主，提供选项／记录／回顾入口，右上菜单编辑；抽取不先进入编辑。

首次空态：“把想做的事装进来，抽一个开始。”主按钮“创建第一个集合”，次按钮“体验一下”。演示使用虚构内容并标“演示”，不写正式记录、不影响统计和轮次。创建只须名称与逐行选项，其他默认。不自动注入正式示例历史，不强制教程或通知授权。

日常：进入集合 → 点击 → 确定并保存唯一结果 → 演出 → 结果卡。主按钮“我做过了”、次按钮“这次不做”、文字按钮“再抽一次”；关闭和重抽保留原状态。可同时存在多条待行动，允许离开 App 后从记录回来打勾。

## 4. 页面和输入规则

### 4.1 集合

首页卡片：图标、名称、可用数、默认样式、轻量待行动数。用户排序，新增最后，拖动排序。搜索名称和描述。归档默认隐藏，独立入口恢复。执行率不做首页最大元素。

| 字段 | 约束 |
| --- | --- |
| 名称 | 必填、trim、1–40 可见字符；同名可共存，ID 不同 |
| 描述 | 可选、最多 200 可见字符 |
| 图标 | 内置许可合适图标，默认骰子；无图片上传 |
| 主题色 | 有限且检查过对比度的调色板 |
| 抽取规则／样式 | 默认允许重复／扭蛋，可选直接揭晓 |
| 执行标准 | 可选，最多 120 可见字符 |

取消不保存；有修改返回需确认；错误在对应字段显示。

### 4.2 选项

标题必填 1–100 可见字符、备注可选最多 300。支持新增、编辑、拖动排序、停用、归档、恢复。停用和归档均不可抽，保留 ID 和历史；归档默认隐藏，恢复不应丢失既有语义。

同集合标题 trim 后 NFC 规范化完全相同则不允许；不忽略大小写、不模糊合并。改内容／顺序不换 ID，不改历史。排序不影响概率。

批量导入：每行标题 → 预览新增、空行、重复 → 确认后一次保存。trim、忽略空行、已有或本次重复列出并默认跳过。超长明确报错，可返回修正，不截断。每批最多 500 行、每集合最多 1,000 项，容量包含停用和归档，不是收费限制。

### 4.3 抽取与结果

顶部集合名、规则、选项入口；中部唯一物件；底部主按钮和规则提示。整轮显示“本轮还剩 X / Y 个可抽”，Y=当前启用且未归档数，X=其中本轮未消耗数，编辑后可变。待行动轻提示可点击，不遮按钮。

处理中锁住所有改变结果、规则、候选池的操作；空池禁抽并提供添加／启用入口，不演假动画。

结果按标题、备注、执行标准、行动按钮排序。标题可换行展开，不能只用省略号。显示“已加入待行动”。结果不自动过期或跳过。历史打开静态结果，不重新抽样、计数或演出。归档集合旧记录可改状态，但不能再抽。

### 4.4 历史与回顾

历史按 drawnAt 倒序、当前设备本地日期分组；按集合和三种状态筛选，搜索抽取时标题。显示当时集合名、标题、时间、当前状态。同选项多次独立保留。状态变更有短暂撤销，也可在详情修改。不提供单条历史删除或重抽抹除；分页或按需加载。

回顾默认全部历史，包括归档集合；五个指标与原始次数，可加比例条；集合可筛选，归档标文字。无评价性文案、无奖惩。只做全时段，不加日周图表。

### 4.5 设置

默认主题跟随系统、音效关、触感开。系统减少动态效果与 App 开关取任一开启，App 不覆盖系统要求。包括备份、恢复、已归档集合、关于与资源许可；源码未公开不放假链接。

独立危险区清空，二次确认所有集合、选项、历史、设置都删除，不影响外部已导出文件；取消不改变数据。

## 5. 三种抽样规则

通用：只抽当前集合启用且未归档选项，P0 等概率 1/候选数，无隐藏权重。可靠本地随机源／标准库安全随机能力，整数范围正确，不用时间戳或有偏取模。可注入确定性测试随机源，不向用户暴露种子。动画只展示已经成功保存的结果。

| 模式 | 规则 |
| --- | --- |
| A 允许重复 | 全部当前可用项均匀选取；A→A 合法，状态不影响资格 |
| B 仅避免连续重复 | 排除该集合最近成功记录的 itemId，不论状态、重启、样式切换；上次项不在池不额外排除；仅 1 项时预先提示“仅 1 个可用选项，本次允许重复”并可抽 |
| C 整轮不重复 | 当前可用项减去 consumedItemIds，成功提交即消耗，不等完成；状态修改不归还资格 |

C 耗尽显示“本轮已抽完”，必须用户点击“开启新一轮”，不自动重置或降级。菜单提前重置需确认；新轮 ID、新 sequence，清空新轮消耗，不动旧历史统计。重启、切页、样式变化不重置。

| 修改 | 对 C 的影响 |
| --- | --- |
| 新增 | 新 ID 立即可抽 |
| 改内容／排序 | ID 和已抽状态保留 |
| 停用／归档 | 移出可抽池，consumed ID 保留 |
| 启用／恢复 | 已消耗仍不可抽，否则可抽 |
| 离开 C | 保留轮次，其他模式不消耗它 |
| 切回 C | 继续原轮；首次进入创建第一轮；设置页注明“继续上次轮次”，独立提供重置 |

规则切换只影响未来，记录保存当时规则。

## 6. 状态、计数与快照

新记录 pending；三种状态可互转。同状态重复点击无副作用。进入 completed 写本次标记时间 completedAt；离开 completed 清空；再次进入写新时间。保存失败回滚 UI 并提示重试。completedAt 不推断实际行动发生时间。

唯一结果成功持久化才增加一次抽取。演示、历史打开、重播／跳过动画、打开结果、拦截连点、空池、失败不增加。保存后返回、后台、终止进程不撤销；历史可找回。重抽新增记录，不删旧、不自动跳过；首次重抽解释，可先跳过原结果。

集合执行率=该集合当前 completed 数/其全部记录数；全局=全部 completed 数/全部记录数，不平均集合百分比。pending、skipped 计分母。零分母显示“—”和“还没有抽取记录”。显示一位小数，内部用整数原数。归档、改名、重置轮次不改变统计。2/10 加 1/1 等于 3/11=27.3%，不是 60%。

执行率不是通关率、阅读进度或内容覆盖率。执行标准抽取时保存快照；空标准显示“按你认为合适的程度，实际做过这件事”。后改成“通关”不改旧“玩过”的含义。

## 7. 视觉、动效和可访问性

方向：“桌上的小小随机收藏馆”，温暖安静、少量玩具感、原创几何形状与轻材质；不堆颜色、贴纸、渐变、玻璃，不做后台表格，不以默认组件堆叠作为成品。本次用户补充偏好：清新淡雅。

| 令牌 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | #F7F3EC | #191D1B |
| 卡片 | #FFFCF7 | #252B27 |
| 主文字 | #26372F | #F2F0E9 |
| 次文字 | #626C64 | #B5BDB5 |
| 主操作 | #355B49 | #B7D2BA 配深色文字 |
| 辅助 | #C6B5DA | #BDA9D0 |
| 描边 | #DADFD4 | #465148 |

建议间距 4/8/12/16/24/32/48，水平 20–24，卡片圆角 24、按钮 16；阴影描边按需。正文 15–16、次文字 13–14、页标题 26–30、结果 24–32，支持文字缩放。系统中文字体，附加字体须核对许可。图标统一、触控目标至少 48×48。360 宽可用，600+ 居中或多列。

完整扭蛋建议 1.6–2.2 秒：触发约 150ms，搅动 450–650ms，掉落 350–450ms，揭晓 400–550ms，按手感微调。胶囊色不表示稀有度。提供跳过动画，展示同一保存结果；减少动态效果用 ≤200ms 淡入或直接展示，无位移摇晃回弹。主按钮足够完成流程，不要求精确拖动、摇手机或连点。

音效轻量、不循环、许可清楚，关闭彻底静音；后台立刻停、回来不重播。触发与揭晓轻触感，不支持则降级。阅读器可读名称、标题、按钮、状态，结果只播报一次。状态不只靠颜色。主文字对比度目标 ≥4.5:1，深浅分别验；200% 字号操作可滚动访问。

## 8. 数据与可靠性

| 实体 | 必须保留的语义字段 |
| --- | --- |
| Collection | id、name、description、iconKey、colorKey、executionCriterion、drawMode、presentationStyle、sortOrder、archivedAt、createdAt、updatedAt |
| Item | id、collectionId、title、note、enabled、archivedAt、sortOrder、createdAt、updatedAt |
| DrawRecord | id、collectionId、itemId、collectionNameSnapshot、itemTitleSnapshot、itemNoteSnapshot、criterionSnapshot、modeSnapshot、styleSnapshot、cycleId 可空、status、drawnAt、completedAt 可空、updatedAt |
| CollectionCycle | id、collectionId、sequence、consumedItemIds、createdAt |
| Settings | themeMode、soundEnabled、hapticsEnabled、reduceMotion |
| BackupEnvelope | schemaVersion、appVersion、exportedAt、collections、items、drawRecords、cycles、settings |

稳定永久 ID，不用名称或下标。时间 UTC 保存、设备当前时区展示，真实时间排序。DrawRecord.id 同时为请求幂等 ID，同一请求重试复用。当前轮是该集合最大 sequence 的轮；新轮不覆盖旧 cycleId。统计从历史派生或可核验重建缓存。

### 8.1 原子抽取

校验集合和候选池 → 唯一请求 ID 和防重入锁 → 只生成一次结果 → 原子保存记录及适用的轮次消耗 → 成功才演出 → 展示并解锁。

连点、回调、重建、重试不重复记录。明确失败既不计数也不消耗；结果不明先按 ID 查，不盲目重抽。保存后崩溃允许动画未结束，但记录与池同时保留。UI 不展示未保存结果或暗换结果。后台停演出，返回直显已存结果；进程终止后历史找回，不自动新抽，不要求永久动画会话。

### 8.2 历史与迁移

改名、标准变化、归档不改旧快照；旧记录仍统计并可改状态。无单项永久删除，只归档和整体清空，准确使用“归档”文案。存储不足、失败、损坏明确提示，不偷偷清库伪装首次运行。升级保留数据；较新数据库格式不兼容时不降级覆盖。

### 8.3 备份

内置资源，无用户图片，UTF-8 JSON 包含全部业务和设置。系统文件保存界面选位置，默认 `random-picker-backup-YYYYMMDD-HHmmss.json`；写入失败不能报成功，取消视为取消。

覆盖恢复不合并：临时解析验证 → 校验版本、字段、ID 唯一、外键、枚举、时间、状态、轮次所属关系 → 预览导出时间和集合／选项／历史数及替换说明 → 提供先导出当前数据入口并明确确认 → 整体提交，失败保留旧数据，成功刷新。

较新版本、损坏或非法关系拒绝；超支持容量明确拒绝，不裁剪。备份明文，说明“可能包含你的集合与行动记录，请自行保管”，无上传或自动第三方发送。

### 8.4 容量

100 集合、每集合 1,000 项，包括停用归档。批量按新增后校验。20,000 条历史是基本浏览与统计验证基线，非截断阈值；达到后不自动删、按实际容量继续保存。达到集合／选项限额说明原因。

## 9. 技术与交付

Android 优先 Flutter；其他平台后续独立验收。实施时选兼容稳定 SDK 和依赖，锁版本，不固定容易过期的版本。抽样、状态、统计、持久化独立于 UI；展示接口扩展主题，不复制随机逻辑。优先成熟事务存储，若文件方案也要完整替换与恢复；不扩展通用 Agent 框架或微服务。

所有功能免费，无必需付费服务。所有者公开前选许可证，MIT 只是候选。核对依赖、图标、字体、音效及署名，不复制专有素材。原创内置绘图／SVG 优先，不依赖网络图片。虚构测试数据，不提交真实集合、历史、备份、签名或密钥。无广告／分析／追踪 SDK、远程字体、账号或后台联网。

交付源码和锁文件、Android 安装测试包和构建方式、README（功能／截图／启动／构建／数据位置／备份）、资源许可与最终由所有者选定的项目许可、验证结果和页面截图及完整扭蛋录屏、已知限制。不自行暂存、提交、推送、发布。

视觉：360/390/430 宽逐页验首页、编辑、抽取、结果、历史、回顾、设置、所有空态；深浅、长中文、备注、多待行动、键盘、200% 字号无溢出遮挡。令牌统一、按钮四态完整、提交立即反馈且慢存储真实等待。约两秒演出、跳过及减动同结果；关闭声音触感和后台行为正确。检查阅读器、对比度、48×48 触控。真机记录型号、系统、构建模式与动画表现，不凭调试模拟器宣称流畅。100 集合、1,000 项/集合、20,000 历史按需加载且统计正确，性能证据带设备信息。
