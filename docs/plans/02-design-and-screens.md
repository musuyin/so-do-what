# 视觉与交互规格：清新淡雅的小小收藏馆

这是一份实现规格，不是已有 UI 的截图，也不代表已经完成视觉验收。先实现以下统一语言，再根据真实设备截图调整细节，不能让每页自由发挥一套风格。

## 1. 视觉主张

“把喜欢的事轻轻收好，有空时抽一个开始。”安静的奶白纸面、鼠尾草绿物件、少量雾紫胶囊和深绿色文字。页面像整洁的日常小工具，不像游戏活动页或后台报表。玩具感集中在抽取物件，其他区域保持清晰克制。

面积参考：背景/卡片约 80%，绿色约 15%，紫色/桃色点缀不超过 5%。不用满屏渐变、玻璃模糊、纸张噪点图片、大面积投影、金色稀有奖品、彩带爆炸、无意义英文眉题。不使用 emoji 代替统一图标系统。装饰不能成为主信息对比度不足的理由。

沿用 PRD 色值，清新感主要由留白、绿色浅底、低密度和几何形态形成，不随意把主文字调浅。

上述为目标组合，实施时计算正文至少 4.5:1，交互边界/图标目标 3:1；淡 outline 不作为唯一输入框边界，输入框用清晰标签和 focus 边线。每个主题实测，未通过调整 token，不能单页打补丁。

规划阶段已按 sRGB 相对亮度公式计算以下不透明组合，结果不是实际页面验收：浅色主文字/卡片 12.29:1、次文字/卡片 5.33:1、按钮文字/按钮 7.48:1；深色对应 12.67:1、7.51:1、7.75:1；浅/深 danger 对卡片分别 6.66:1、8.12:1。实施后的透明叠加、禁用态、其他背景和焦点边界仍需另验。

间距：4/8/12/16/24/32/48。手机左右 20，≥390 可 24，组件内边距 16 或 20。卡片圆角 24，按钮 16，输入框 14，状态小标签 10。卡片默认细描边，不叠加明显阴影；浮层可有轻阴影，扭蛋物件有小椭圆投影。

## 3. 自适应与组件

- <600：单列集合卡，避免 360 宽时长标题挤成窄列；底部导航固定 SafeArea，内容滚动。
- ≥600：内容居中 maxWidth 960，集合卡两列，卡片最小宽 260；表单/结果 maxWidth 560；扭蛋详情 maxWidth 640。不新增桌面平台交付。
- 200% 字号：信息纵向排列，统计卡可退单列；不缩小字体、不禁用 TextScaler。所有操作区可滚动到达，键盘出现时自动让字段及保存按钮可见。
- `CollectionCard`、`StatusChip`、`PrimaryAction`、`EmptyState`、`InlineError`、`MetricTile`、`ResultContent`、`ConfirmSheet` 为共享组件。图标使用同一套 rounded 风格，集合图标可选骰子/电影/书/游戏/餐具/步行/音乐/星星八个 key，不动态拼 Icons 名称。
- Dialog/bottom sheet 不嵌多层固定高度；全屏表单处理长内容和键盘，结果用独立可滚动路由，避免把长中文挤在小弹窗。

## 4. 页面规格

### S01 集合首页

```text
安全区
我的集合                         [设置]
把喜欢的事，留给下一次有空。        （辅助文字）
[ 搜索集合                         ]
[骰子底块] 今晚做点什么         [›]
           8 个可用 · 扭蛋
           还有 2 条待行动          （有数据才出现）
卡片间距 12
[            ＋ 新建集合           ]
底部安全留白
[ 集合 ]       [ 记录 ]       [ 回顾 ]
```

主标题与搜索间 24。卡片内容区 minHeight 104，但允许增高；名称最多两行首页可省略，详情必须完整。卡片不展示醒目的执行率。菜单“调整顺序”“已归档”；拖动仅在调整顺序态出现把手。新建按钮在列表尾且首页右上可有等效新增入口，但不要同时堆三个新增按钮。

无集合：中间原创双胶囊静态图、PRD 空态文案、主“创建第一个集合”、次“体验一下”；设置仍可进入恢复。搜索无结果：“没有找到匹配的集合”，提供清除搜索，不展示创建首集合空态。加载与读取失败分开，不能失败时伪装空库。

### S02 创建/编辑集合

全屏：返回 / 标题 / 保存。名称和逐行初始选项优先；描述、执行标准在下方；图标、主题色用有限网格；抽取规则、展示方式用带解释的单选组，不暴露内部 enum。

创建时初始逐行输入经预览再一并保存；也允许创建空集合，之后引导加选项。编辑页不展示初始导入字段。规则三项各有一句说明，C 有“继续上次轮次”和“重置本轮”独立操作；切规则不暗重置。样式只有扭蛋/直接揭晓，无未来主题灰色占位。

未保存离开确认：“放弃这次修改？”“继续编辑”/“放弃修改”。输入最大长度显示 x/限额，错误就在字段下；不 silent maxLength 截断粘贴内容。保存失败保留表单。

### S03 选项管理与批量预览

顶部集合上下文、搜索，新增/批量导入在工具栏。主列表含启用和停用项，停用明确标“已停用”；每行标题、备注摘要、更多按钮，右侧启用开关需有语义标签。归档项独立筛选入口。行点击编辑，更多菜单归档；没有删除。

排序态显示完整集合内选项，含归档标签，禁止搜索；拖动完成点击保存一次提交，取消恢复原顺序。恢复不会强行启用原停用项。

批量导入两步：粘贴 → 预览（新增 n、重复 n、空行 n、错误 n）。每类可展开；显示原行号、原因；错误行保留原输入，用户返回修正。按钮“添加 n 个选项”，零新项或有错误禁用。提交失败停在预览，可重新验证后重试。

### S04 集合详情 / 抽取

```text
[‹] 今晚做点什么                  [···]
    仅避免连续重复                 （可打开设置）
[ 选项 8 ] [ 记录 ] [ 回顾 ]

             原创扭蛋机
           （约 248×284）

       本轮还剩 3 / 8 个可抽        （仅 C）
       [        抽一个        ]
       还有 2 条待行动  ›           （无则不占位）
```

扭蛋占视觉焦点但不能挤掉按钮；短屏时整体可滚动，不能硬分三个 Expanded。直接揭晓用较小的静态胶囊/信封符号，不保留暗示会转动的机器。无可用项替换主按钮为“添加选项”，旁边“管理已有选项”；C 耗尽显示“本轮已抽完”+“开启新一轮”，按下只开轮，用户再点抽取。仅一个可用项且 B 时**抽前**展示规定提示。

菜单：编辑集合、调整/管理选项、C 的重置本轮、归档。归档确认说明保留历史，可恢复；归档后返回首页。菜单中危险行为用文字解释，不以红色删除图标代替归档。

committing 显示真实保存中，按钮即时禁用；不提前展示抽中标题，也不开始完整揭晓演出。presenting 显示“跳过动画”，其语义是同结果立刻揭晓。返回操作离开但保留已存结果；后台返回直显结果。

### S05 结果页 / 历史详情共用内容组件

可滚动路由，顶部关闭，居中小装饰胶囊；标签“这次抽到”，完整标题，备注，执行标准浅底区域。空标准使用 PRD fallback。新抽显示“已加入待行动”；状态更新后显示实际当前状态，不能仍提示待行动。

操作：满宽主“我做过了”、次“这次不做”、文本“再抽一次”；已完成主按钮变为已选状态但允许通过“修改状态”改为 pending/skipped。三状态编辑明确可达，不能只有两个单向按钮。保存中仅状态操作锁定。

首次再抽用轻确认说明：“再抽会新增一条记录，这条仍保留为待行动。”若原记录已是其他状态，文案按实际状态变化，不声称仍 pending。继续后设置首次提示已读；此设置写入失败不影响抽取正确性。历史打开不播放完整演出、不播报“新结果”；归档集合隐藏再抽按钮并解释“集合已归档，恢复后可继续抽取”。

标题完整换行默认显示，不给 100 字标题固定两行裁剪；备注超长可展开。屏幕阅读器揭晓只 announce 一次，rebuild 不重复。内容的语义树不是整页一个标签。

### S06 记录

标题“记录”；搜索历史标题；状态 chips“全部 / 待行动 / 已做过 / 这次不做”，集合选择器支持归档与同名集合的描述/图标区分。默认全部、时间倒序。按本地日期标题分组，条目显示快照集合名、标题、时刻、文字状态标记。

每页 50，滚动加载。加载更多错误只在底部重试，不能清空已有列表；新筛选加载则用对应 loading。空历史“抽出的结果会留在这里”；筛选为空“没有符合条件的记录”。状态保存后 snackbar 约 5 秒“已标记为已做过 · 撤销”，撤销失败可重试且不谎报。

### S07 回顾

标题“回顾”，辅助“看看抽到的事，有多少成为了行动。”集合筛选默认全部。主卡执行率大字 + “已做过 3 次 / 共抽取 11 次”，细比例条；下方待行动/这次不做两卡，另外明确总抽取和完成次数，允许与主卡重复作为可扫读数据。

零记录主值“—”，说明“还没有抽取记录”，不画 0% 失败色条。集合摘要按用户顺序而非完成率排名，显示名称、次数、率；归档有文字。深浅主题比例条不靠红/绿评价。无周/月切换、饼图动画、覆盖率或积分。

### S08 设置、备份与恢复

分组：外观（主题、减动）/反馈（音效、触感）/数据（导出、恢复、归档）/关于（版本、资源许可、真实公开源码链接）/危险操作（清空）。主题跟随系统默认；系统减动已开时显示“系统已启用”，App 开关不能强行恢复动画。音效默认关。

导出页提示明文隐私和文件保存位置由系统选择；恢复先选文件，再校验 loading，再预览导出时间与数量。预览按钮：次“先备份当前数据”、主“替换并恢复”。确认文案列出当前数据会被全部替换，不写技术词。验证失败停在选择/错误区，当前页面数据不变。

清空二次确认：进入危险区 → 点击清空 → 确认对话框“所有集合、选项、记录和设置将被清空。已经导出的备份文件不会被删除。” → 明确“清空全部数据”。成功回空首页并恢复默认设置。无假源码地址，无预先声明 MIT。

## 5. 扭蛋物件绘制规格

采用 CustomPainter 与 Flutter 组合实现原创矢量形状，无网络素材、无额外动画运行时。开发预览尺寸 280×320 逻辑像素，绘制坐标归一化后等比缩放，视觉最小宽 220。不可用截图作为不可交互的最终机器。

图层从后到前：

1. 地面投影：椭圆 center(140,294)，width156 height14，深绿 8% alpha，减动时也静态。
2. 底座：rect(58,174,164,112)，radius24，鼠尾草绿；底座脚(72,278)与(186,278)，小圆角。
3. 透明球仓：center(140,106)，radius88；浅米白实体填充加轻描边和一段高光弧，避免昂贵实时 blur。
4. 6–8 个可见装饰胶囊，radius14–18，限定球仓内 clip；低饱和绿/紫/桃，不代表真实选项个数，不与随机源交互。
5. 顶部帽与球仓底沿：同主绿，线宽统一；无品牌字和稀有标记。
6. 旋钮：center(140,215)，radius23，奶白内盘与深绿把手；出口 roundedRect(108,251,64,25)。
7. 掉落胶囊独立 overlay，从出口落到 center(140,296)，揭晓时可在扩展绘制区显示，不能被父 clip 截断。

深色机身仍保持轮廓层级，球仓用深 surface，胶囊适当提亮。交互语义是一个“抽一个”按钮，装饰胶囊全排除 Semantics；主按钮为首要可达入口，物件点击与它调用同一控制器。

## 6. 动画时间轴与生命周期

目标演出 **1,850ms**（不包括提交等待时间）；一个归一化 AnimationController，阶段不分别写 Timer，防止重复回调。

| 时间 | 动作 | 曲线/幅度 |
| --- | --- | --- |
| 0–150ms | 旋钮按下并旋转 | scale 1→0.97→1，转约 50°，easeOut |
| 150–750ms | 胶囊轻搅动 | 预定轨迹，位移 4–10px，转动 ≤12°，不持续剧烈摇屏 |
| 750–1150ms | 胶囊落下与轻回弹 | 约 32px 下落、一次 5px 回弹 |
| 1150–1700ms | 两半打开，结果卡渐显 | 胶囊两半各移动约 18px，卡片 opacity0→1、translateY12→0 |
| 1700–1850ms | 安定、操作可见 | easeOut，不加多余等待 |

动画接口接收不可变 `DrawRecord` 和 `onReveal`，不接 RandomSource/Repository。`onReveal` 必须幂等，skip/completed/background 都经同一 revealOnce。按钮防重不靠动画完成回调释放；finally/生命周期退出也处理状态。

直接揭晓：保存后立即结果；有效减动：无位移旋转弹跳，淡入 150ms 或零动画。中途系统开启减动也立即结束到同记录结果。应用后台停声音与触感、停止 controller；返回直接结果，不从头播放。无无限 idle 摇晃，空闲物件静止。

两段轻音效（触发/揭晓）和对应轻触感；音效关闭不创建播放任务，触感关闭不调用平台接口。音效需原创合成或明确再分发许可，放 assets/sounds 并记录来源；不能空开关冒充实现。Assets 在 pubspec 注册，原创绘图在许可清单中说明。无音频硬件或触感失败不影响已保存业务结果。

## 7. 视觉验收输出

每个页面浅深色截图，以及 360/390/430 宽的关键长内容截图；600+ 截图检查居中。空态、错误、禁用、保存中、C 耗尽、仅一项 B、归档历史、200% 字号和中文键盘都覆盖。完整扭蛋录屏、跳过/后台/减动录屏保存为验收附件。所有截图必须来自实际运行实现，不能用本规格草图替代。
