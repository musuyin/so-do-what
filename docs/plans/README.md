## 计划补充决策（非 PRD 原文）

| 编号 | 默认决定 | 理由 |
| --- | --- | --- |
| D01 | 库内 UTC 毫秒整数，JSON UTC ISO 8601 Z 字符串 | 易排序、易交换；统一毫秒精度 |
| D02 | 相同毫秒用持久化 drawOrdinal 破平局；JSON 数组顺序保留它 | “最近成功结果”和分页顺序明确 |
| D03 | 归档不修改 enabled，恢复保留停用状态 | 避免恢复意外改变抽样资格 |
| D04 | 标题唯一性覆盖归档和停用项 | 保持同集合全局不重名；重复提示可引导恢复 |
| D05 | 搜索 trim+NFC 后字面子串、不区分查询语法，不默认折叠大小写 | 行为确定；避免 SQLite LIKE 特殊符误匹配 |
| D06 | 搜索或过滤中不允许拖动；进入“调整顺序”用完整列表 | 避免局部排序破坏全局次序 |
| D07 | 归档保留 sortOrder，恢复回原相对位置；规范化排序覆盖归档项 | 保证备份往返与新建末尾一致 |
| D08 | 明确回滚的抽取仍保留本次候选快照和选择，重试不重抽 | 实现一次请求一个结果 |
| D09 | 减动有效值为系统要求 OR App 设置；减动取代扭蛋 | 可访问性优先 |
| D10 | 无历史条数硬上限；备份容量只按明确资源边界拒绝，不截断 | 20,000 是验证基线 |

没有未决事项阻挡编写原型。正式应用名、正式包名、项目许可证、签名和公开渠道由所有者在公开前决定；不能自动选择 MIT 或发布。
