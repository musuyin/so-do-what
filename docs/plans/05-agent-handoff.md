# 给后续编码代理的交接指令

**本文件是未来启动指令。当前用户只授权 plan；创建或阅读本文件不构成实现授权。**

用户明确要求开始编码后，可复制以下内容：

```text
请在 D:\Coding\Projects\so-do-what 实现事件随机选择器的 P0。

先读取 AGENTS.md、docs/PRD.md、docs/plans/README.md，再按 README 顺序读全部计划。
docs/PRD.md 是用户 PRD 的结构化保留版；计划补充默认值见 README 的 D01–D10。
用户业务规则优先，不能因为计划遗漏或实现麻烦削掉 P0。

按 docs/plans/03-implementation-tasks.md 的 T00–T12 逐步执行。
每次开始先看 git status 和 docs/implementation-status.md（若已存在），辨别已做/未做，不重建覆盖他人修改。
说明本次具体任务，然后实现它、运行对应验证、记录真实结果，再继续下一依赖任务。
没有项目状态文档时先建立，初始各任务均未完成。
完成一个任务后若当前授权仍覆盖后续工作，继续执行；不要每一步询问常规实现细节。

默认 Android/Flutter，SQLite 事务，显式注入，SDK 页面控制器。
依赖和 API 以实际锁定稳定版本为准，先做最小平台能力验证。
工具链暂不可用不改成 Web，不宣称已经构建。

设计严格读 02-design-and-screens.md：奶白、鼠尾草绿、雾紫点缀、系统中文字体、留白。
原创几何扭蛋按坐标和 1850ms 时间轴落地；其他页面精简克制。
360 宽、深浅、200% 字号、中文键盘和长结果必须可操作。
不能用默认控件堆叠、假入口、静态图或虚构统计交付。

以下不变量不能简化：
1. 三种候选规则；B 以最近成功提交为准；C 跨重启和切模式保留，编辑影响遵循 PRD。
2. requestId 幂等，结果和轮次同事务提交，成功后才演出；结果不明先按 ID 查询。
3. 再抽新记录，旧记录不自动跳过；完成属于记录，状态同态更新无副作用。
4. 统计从全部记录派生，归档仍计入；全局率不是集合百分比平均。
5. 名称、标题、备注、执行标准的历史快照不随实体编辑变化。
6. 备份先完整验证再确认覆盖，恢复失败旧数据不变；绝不先清库再尝试导入。
7. 演示依赖隔离，正式记录不注入示例。
8. 20,000 历史是测试基线不是上限；归档/停用计入实体容量。
9. 不自动清坏库、不覆盖较新格式；所有成功提示必须有提交/写入成功证据。

每任务交付实际变更、验证、限制。按 04-verification.md 覆盖 A01–A22、布局、离线、设备和容量。
真实设备不可用时保留未验证，不将宿主单测或模拟截图称为真机验收。
只在问题影响需求/数据安全且计划无法推导时请求澄清；其他使用计划默认值。

不实现 P1、账号、后端、广告、收费、远程统计或推送。
不提交个人数据、不自行选项目许可证、不使用未知许可素材。
不暂存、提交、推送或公开发布，除非用户另行明确授权。
不要自动启动子代理；仅在用户或适用指令明确要求时使用。

最终交付源码/lockfile、Android 测试包、README、许可清单、截图/录屏、验证和已知限制。
许可证/签名/正式名称或包名等公开前事项不能伪称已经决定。
```
