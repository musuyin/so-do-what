# Original local sounds

`turn.wav` and `reveal.wav` are original synthesized tones created for this project on 2026-11-13. Mono PCM 16-bit, 22,050 Hz; sinusoidal tones shaped with a sine-squared and exponential envelope. No samples or third-party recordings are used. They are project-owned assets; redistribution follows Apache-2.0, selected by the owner on 2026-11-13.
